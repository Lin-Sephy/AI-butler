# AI 身体状态计划管家 — Web App 产品设计 & 开发方案 v1.0

> 2026-04-08 Sephy + 小克制定
> 替代 v0.1 迁移方案。产品方向从"迁移 Streamlit"变为"全新交互体验"。

---

## 一句话定义

一个像素风的 AI 陪伴空间——用户在房间里生活、在书房里专注、在菜园里种任务，跟宠小白一直陪着。不是更漂亮的计划工具，是一个让人想打开的地方。

## 核心设计理念

> "我们可以把小管家形象设计成随身的跟宠小动物，走哪跟哪那种。"
> "记录的时候我们就种一颗菜，点击开始就是成长，最终可以收菜！"
> "这个交互弥补了只依靠 AI 的弊端，我们不用担心被纯 AI 本体取代，因为我们设计了交互，这是我们的壁垒之一。"
> — Sephy

**竞争壁垒：** 市面上的专注软件（Forest 种树、番茄钟）有游戏化但没有 AI 陪伴。AI 聊天产品有陪伴但没有交互场景。这个产品把两个拼在一起。纯 AI 产品容易被更强模型替代，但用户种的菜、布置的房间、跟宠的性格——这些沉淀在产品里，换不走。

**商业模式：**
- 卖家具（审美付费）
- 卖菜地格子（功能付费）：菜地初始 4 个格子。记录任务=占一个格子，完成收菜后格子才空出来。超过 4 个任务时必须替换掉一个，或者丢弃记录，或者花钱扩格子。越勤快的用户格子流转越快，越拖延越需要买格子——激励完成，惩罚拖延。

## 产品设计

### 画风

像素风，俯视角（类 RPG 视角）。角色可以上下左右移动，靠近物体触发交互。技术实现难度低，审美有辨识度。

### 三个空间

#### 1. 卧室 — 休息

- 只有床
- 精力低时，跟宠建议用户到床上休息，用户决定点不点
- 点击床 → 角色躺下 → 休息状态

#### 2. 书房 — 专注（正计时）

- 桌子 + 电脑 + 时钟显示
- **正计时模式**：用户坐到书桌前，计时开始，适合开放式专注
- **白噪音**：书房内可播放白噪音
- 桌面上显示当前时间
- 想休息时可以点击椅子，角色走过去坐下 → 休息状态

> "书房就是正计时，而且有播放白噪音的功能。我敢说目前市面上暂时没有一版专注软件是这样设计的。"

#### 3. 菜园 — 任务可视化（倒计时）

- 室外空间，菜地 + 水井 + 长椅 + 花草装饰
- **种菜 = 记录任务**：用户点击"记录"时，菜园里种下一颗菜苗
- **专注时间 = 生长时间**：用户设定专注时长，倒计时开始

**菜苗生命周期：**

```
记录任务 → 菜苗自动种下，占一个格子
        ↓
    开始任务，选择模式：
        ↓
    ┌─ 设了时长 → 菜园模式（倒计时，强制蹲在菜园）
    │   进度 < 50% 退出 → 菜苗死亡，需要重新种
    │   进度 ≥ 50% 退出 → 退回中苗状态，保留进度
    │   进度 = 100%      → 长成，可以收割！
    │
    └─ 不设时长 → 书房模式（正计时，自由专注）
        菜苗根据累计专注时间在菜园里自动生长
        （如：满 25 分钟长到中苗，满 50 分钟成熟）
        结束专注后去菜园收割
```

菜苗永远在菜园里，但生长不限于人在菜园蹲着。菜园是冲刺模式（限时、强制、高压），书房是自由模式（不限时、可中断、低压）。菜苗都会长，只是长法不同。

> "如果有一个记录我们就种一颗菜，点击开始就是成长。中途离开不到一半那中苗就死了要重新种，如果完成了一半多自动退回到中苗的状态，完成才可以收割。"

### 跟宠：小白

- 像素风小动物，始终跟随用户角色移动
- 基于现有 AI 聊天系统（DeepSeek），对话框嵌在画面底部
- 精力低时主动建议去卧室休息
- 人格可选（INFP/INTJ/INTP）
- **自粘贴性格**：用户可以自己填写性格描述（有字数限制），塞入 prompt 的 persona 字段

> "可以自粘贴性格进去，估计又可以骗一群人进来。"

### 交互方式

- **点击/键盘**控制角色移动
- **靠近物体**触发交互提示（坐下、浇水、躺下、回家）
- **聊天框**始终在底部，既可以打字聊天，也可以通过场景交互触发对话
- 降低启动成本：用户不用想"我该说什么"，点一下就能开始

### 系统 UI

- 左上角：场景名 + 时间 + 日夜图标
- 右上角：精力条（对应现有精力系统 1-5 档）
- 底部：聊天对话框（小白的回复 + 用户输入）
- 场景切换：卧室 ↔ 书房 ↔ 菜园（点击门/路径切换）

 用户一天的完整流程

  早上起床，打开 app：

  1. 用户打开 app → 看到什么场景？（漏洞：没定义默认场景。卧室？上次离开的地方？）
每一天自动重置为卧室，一天内中途离开为上次离开的地方。
  2. 小白打招呼 → 根据时间段说不同的话？现在的"来啦～"还是要改？
起床的时候变成：user你醒啦！！其他时候还是：“来啦”
  3. 精力值 → 现有系统有静默继承（用昨天的）和手动设置。在像素世界里精力怎么设？点右上角精力条直接调？还是小白开口问？
在左侧我们还是有个<<的标，点击这个就弹出来精力值，记录的任务，用户的自我设定，小白的记忆等等我们在streamlit已经做好的这些。另外小白的名字得改，默认可以叫小白但是要给用户一个命名的功能。
  4. 如果是新的一天 → 跨天逻辑已有（清空对话、情绪过期）。每日循环任务呢？现在系统会自动生成 idle任务，在菜园里是自动种下还是要用户手动种？
凡是记录的就自动种下占一个菜田格子，每日循环任务也每天自动占一个菜田格子，并且是菜苗状态。点击这个菜苗或者在侧边框里面点击开始任务才会开始。
  

  用户想工作：

  5. 用户跟小白说"我要写论文" → AI 返回信号 → Python 判断触发推任务 → 出现"记录"选项
  6. 用户点记录 → 菜园里种下一颗菜苗（占掉一个格子）
  7. 然后呢？用户要走到菜园去点菜苗才开始倒计时？还是可以在聊天框里直接开始？
走到菜园点击菜苗可以倒计时。如果在侧边栏里面点击开始就自动跳转到菜田界面开始蹲着种地。在聊天框里面只显示当前消息和底部弹出的按钮。聊天历史记录可以点击展开再显示全。这个就抄市面上的设计。
  8. 如果用户只是想开放式专注（不带具体任务），直接去书房坐下就行。但如果有任务记录了，书房的正计时和菜园的倒计时怎么区分？用户怎么选择？
规则：**种下 ≠ 开始**。小管家推荐任务记录到侧边栏的同时，自动在菜园种下一颗菜苗，占一个格子（菜苗状态，未开始生长）。点击开始 = 让这颗已经种下的菜苗进入生长模式——默认不限时长，走书房正计时（菜苗按累计专注时间在菜园里自己长）；用户选带时长则走菜园倒计时（蹲菜地里强制生长）。正计时同时只能一个。

如果用户自己选择去书房坐下，那就弹出一个是否开始任务的选项，让用户自己设置任务开始。也可以自己点击空白菜田建立任务。

  专注中：

  9. 菜园模式：倒计时跑着，菜苗在长。用户能离开菜园去别的房间吗？离开算不算"退出"？还是倒计时继续跑，只是看不到菜苗了？
不行，种地就是种地，种地只能蹲着种不能在床上种，强制固定在菜地里面，除非自己选择退出状态，但是那样任务就算中断，菜苗自动退回成长。但是如果用户实在想开小差了，点退出，这里有两个选项：退出任务/去休息。选1就是任务中断，选2就是可以站起来自由活动了（限制十分钟）这时候菜苗的状态可以保持不变。一次任务里最多休息一次。
  10. 书房模式：正计时跑着，白噪音放着。用户离开书房去菜园浇水算中断吗？
离开当前场景都算中断，因为用户只有一个人，不能同时做两个任务。
  中途想休息：
  11. 在书房 → 点击椅子 → 坐下休息。
这里有个区别，书房场景里面没椅子，只有一个桌子一个电脑面对着用户。正向计时有结束任务/休息一会儿，这两个选项，用户点击休息一会儿就可以自由活动。
  12. 和去卧室躺床有什么区别？椅子 = 短暂休息，床 = 结束今天？还是纯粹是场景不同、功能一样？答：想去哪去哪。

  完成任务：

  13. 倒计时到 100% → 菜苗成熟 → 用户去菜园点击收割 → 格子空出来。
用户就在蹲着种地，种完了菜长成了，用户可以点击收割，菜就进筐。这里我们要做一个储物格子，一个菜一个框然后右侧显示数字即可，花时间越久种出的菜越高级，可以卖的钱越多，钱可以在商城购买家具。
  14. 小白说"干得漂亮"之类的
  15. 收割后精力会变化吗？现在系统里休息类任务完成后会弹精力确认。
如果检测到任务框里面用户完成三个任务了才会弹一次精力确认，或者用户自己说累了小管家也会感知到。
 晚上收工：

  16. 用户去卧室躺下 → 小白说晚安？精力重置？还是等第二天跨天逻辑处理？
精力不重置，万一用户只是想躺上去玩呢。精力就暂时按照现有逻辑。

其他漏洞：
  17. "再聊聊"按钮 → 现在用来清除推荐回到纯聊天。在像素世界里怎么表现？聊天框里的按钮？现在 Streamlit
  里用来清除推荐回到纯聊天。在像素世界里还需要吗？还是聊天框底部照样弹两个按钮（记录/再聊聊）？
  就在聊天框的底部弹出“记录”和“再聊聊”两个选项就可以了，还是照旧。

  18. 场景切换怎么走？

  用户从书房去菜园，是点一个门？走到画面边缘？还是有个场景切换按钮？
  答：场景切换按钮。如果侧边栏点击开始而用户在卧室，那就弹出来一个是否切换到xx的选项。比如用户选择的是正计时那就切换到书房，用户选择倒计时那就切换到菜地，如果用户正好在菜地而选择倒计时，那么就不用弹切换场景的选项。这时候用户点击开始，小人自动走到对应菜苗那边蹲下开始种地。


  19. 预定任务

  现有系统支持"下午三点写报告"。在菜园里怎么表现？种子旁边显示个时钟图标？到时间了小鸡提醒？
  如果这个预定是在今天的，那就自动会种进菜地然后头上显示时间。到时间了小鸡也会自动提醒一次。如果预定的是明天的任务那么暂时不种进菜地，第二天自动种进去，提示流程如上。

  20. 设置页面入口

  自粘贴性格、小鸡命名、人格选择、手记这些放在侧边栏里就够了？还是要一个单独的设置场景（比如书房里点电脑
  打开设置）？放在侧边栏，不过度设计。

  21. 首次使用引导

  新用户第一次打开，怎么知道可以种菜、可以去书房？小鸡带着逛一圈？还是自己探索？
  新用户打开固定场景到卧室，然后小鸡可以提示创建第一个任务，引导就结束了。

  22. 书房正计时的结束
