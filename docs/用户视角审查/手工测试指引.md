### ✅ A-#4：thinking 气泡动态文案

**操作**：发一条比较复杂的消息（或 plan 模式下的排计划指令），等 DS 回复。

**期望**：
- 0-3s：只有白鼬思考 SVG + 头顶 3 点泡泡（和原来一样）
- **3s 后**：白鼬下方小灰字出现 "在翻你任务栏..."（plan 模式）或 "在想怎么说..."（闲聊模式）
- **8s 后**：文案换成 "让小白慢慢想..."
- DS 回复一到 → 文案消失 + AI 气泡出现

**快速模拟**：网络正常时 DS 可能 2-3s 就回，体验不到 phase 2。可以在 plan 模式让 DS 做复杂调度（"帮我把这周任务重新排一遍"），跑 tool calling 会拖到 8s+。

### ✅ B-1（最高优先级）：FocusOverlay 切 tab 计时器不丢秒

**这条必测 —— 之前是在毁专注数据**。

**操作**：
1. 新建一个 25 分钟倒计时任务，点开始
2. 等 10 秒确认计时器走了
3. **切到别的 tab**（浏览器其他页或切到微信等 app）放 **2-5 分钟**
4. 切回来

**期望**：
- 计时器**立即**显示"已过去 N 秒"——不论切走了多久，回来第一眼就准

**额外测试 pause**：走一会儿点暂停，等 1 分钟，再点继续。期望：暂停期间的时间**不计入** elapsed。

## 二、后端端到端测试（需要真数据）

### ✅ B-3：任务结转 + abandoned 2 天过滤

**准备**：登陆 Supabase Dashboard → Table Editor → `task` 表。

**测 idle 结转**：
1. 新建一个 idle 任务（通过前端 "+ 新建任务" 按钮）
2. 在 Supabase 里手动改这条记录的 `created_at` 为 **3 天前**（例如今天是 2026-04-22，改成 `2026-04-19T10:00:00+08:00`）
3. 刷新前端任务页

**期望**：
- 任务**不显示**在今日列表里（被 sweep 成 abandoned）
- Supabase 里看该行 `status` 变成 `abandoned` + `completed_at` 刚刚填上

**测 abandoned 过滤**：
1. 前端建一个任务 → 点"放弃"
2. 去 Supabase 里把 `completed_at` 改成 **3 天前**
3. 聊天 plan 模式让 DS "看看最近 7 天做了什么"（会调 `query_tasks`）

**期望**：DS 回复里**不提**这条陈年放弃任务。后端日志可以看 `_tool_query_tasks` 返回的 records 里没这条。

### ✅ B-4：create_tasks 加 scheduled_at

**操作**：聊天页切到 **任务模式**（顶栏 toggle 向右），发：

> "明天早上 9 点提醒我去跑步"

**期望**：
1. DS 应该调 `create_tasks` 工具（看 backend 日志有 `[Chat] 调用 create_tasks` 之类）
2. 传的参数里包含 `scheduled_at: "2026-04-23T09:00:00"`（日期是明天）
3. 任务写进 DB，`status = scheduled`（不是 idle）
4. `PlanConfirmModal` 弹窗显示这条任务，包含时间

**不同表达试一遍**：
- "今天下午 3 点开会"（→ `2026-04-22T15:00:00`）
- "周五 14:30 见导师"（→ DS 要推算日期）
- "明早 9 点"（期望 `09:00`）

**容错测试**：DS 如果传了奇怪格式（比如只传 "9:00"），后端 `_parse_scheduled_at` 会补今天，也能写成功。

## 四、测试后的常见分支

- **Render 冷启动文案一直停在第一档**：Render 可能还没 sleep 过，你的"打开"直接热访问了。可以直接把 `WAKE_MESSAGES[wakeStage]` 的 stage 初值改成 1 或 2 手动看效果
- **切 tab 计时还不准**：检查 Chrome 不是把浏览器整个最小化了（那样可能连 visibilitychange 都不触发）。也看 DevTools → Performance 是不是开了"Throttling: 4x slowdown"
- **"切到任务模式 →"按钮不出现**：确认 mode 是 chat 不是 plan（顶栏 toggle 看左右颜色）
- **DS 不调 create_tasks**：检查你确实在 plan 模式 + 输入里给了明确"记下来"类信号 + Render 环境变量 `DEEPSEEK_API_KEY` 还有余额
