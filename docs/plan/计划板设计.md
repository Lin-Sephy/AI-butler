# 计划板设计（2026-04-24）

> 2026-04-24 与 Sephy 对齐的任务页重设计。推翻前一版「时间轴 + 未定时区 + 已过时段 + 完成/放弃折叠」多层混合布局，改成更简的**日计划板**单一组件。

---

## 设计总览
─────────────────
‹‹    计划板    ››    ← 表头永远显示"计划板"三字；‹‹ 翻昨天，›› 翻明天
─────────────────
+ 新建任务
─────────────────
【日计划板内容】
  · 今天视图：
      ▼ 已过 N 个    ← 默认收起
      (当下/未来任务时间轴)
  · 昨天/之前视图：
      (全日任务时间轴，按 scheduled_at 排序，点击<<切换)
  · 明天/之后视图：
      (全日未来任务时间轴，点击>>切换)
─────────────────
【未定时区】           ← 固定，不随日期切换变化
  (无时间任务列表)
─────────────────    
```

**核心设计原则：**
- 视觉层级只有**两层**：上方"未定时"（无时间的事）+ 下方"日计划板"（有时间的事，按日翻）
- 表头始终显示"计划板"三字，不显日期、不做"昨日/历史/预定任务"等相对称呼——用户自己按 `‹‹` / `››` 翻页，UI 不需要告诉他在哪一天
- 砍掉旧的「已完成」「已放弃」独立折叠区——合并进"已过"

---

## 各区域精确定义

### ① 未定时区（顶部固定）

**内容：** 今天创建且无 `scheduled_at` 的**活跃**任务（status ∈ `idle` / `paused`）
- 包括：用户手建的无时间任务、循环任务（无 hhmm）今日 spawn 出的实例
- 不包括：今天完成/放弃的无时间任务（→ 进「已过」折叠）
- 不包括：其他日期的任务

**行为：** 日期切换时**不变**——它是"当下没定时间的事"，跨日概念。

### ② 日计划板（下方，按日翻）

**表头：** `‹‹  计划板  ››`（字面就是"计划板"三字，无日期）

**当 date == 今天：**
- 「已过 N 个」折叠（默认收起）：
  - 今日 `scheduled_at < now` 的**所有**任务（含 scheduled / idle / paused / completed / abandoned）
  - 今天 created 且无 `scheduled_at` 的 **completed / abandoned** 任务也丢进来
- 时间轴区：
  - 今日 `scheduled_at >= now` 的任务
  - + `status == executing` 任务（即使 scheduled_at 已过——还在做就不算"已过"）

**当 date != 今天：**
- 无「已过」折叠（一整天都属于过去或未来，不需要再分）
- 无未定时区（那是今天的）
- 时间轴区：该日所有 `scheduled_at` 落在该日的任务（含所有状态），按 scheduled_at 升序

### ③ 「已过」折叠的收纳规则

今天「已过」折叠 = **今天所有不需要再盯的任务**，包括：
- `scheduled_at < now` 且 `status != executing` 的（今日）
- `scheduled_at IS NULL` 且 `status ∈ (completed, abandoned)` 且 created today

折叠内任务卡片行为跟现有一致：idle/scheduled 可点 `▶ 开始`、completed 可删除、abandoned 可恢复/删除。

## 新建任务（NewTaskModal）

**字段：**
- 做什么（keyword，必填）
- 时长（chip 选 25/35/45/60/90/120 或自填，默认 25）
- ☐ **每日循环** toggle
- ☐ **定时** toggle
  - 勾后露出 picker
  - 无循环 → 日期 picker（`min=今天`）+ 时间 picker，两个都必填
  - 有循环 → 只要时间 picker（每天这个时间）
  - 无循环 + 定时 submit 前校验 `picked >= now - 60s`

**四种组合对应的后端调用：**

| 循环 | 定时 | 调用 | 建成什么 |
|---|---|---|---|
| ✗ | ✗ | `POST /api/task/record` | idle 任务 |
| ✗ | ✓ | `POST /api/task/record` + `scheduled_at` | scheduled 任务 |
| ✓ | ✗ | `POST /api/recurring` | 无时间循环模板 |
| ✓ | ✓ | `POST /api/recurring` + `scheduled_hhmm` | 每天 HH:MM 循环 |

## TaskCard 视觉

- **无左侧 dot**（砍了，跟旧版区别在这）
- 按钮纯图标：`▶` 开始/继续 / `⏸` 暂停 / `✓` 完成 / `✗` 放弃 / `×` 删除 / `↺` 恢复
- 循环任务多一个 `每日` chip
- `executing` 状态：背景 `primary-soft`（浅蓝）+ 整圈主色 border + 左侧 3px 加粗
- `completed` / `abandoned` 状态：文字 line-through + opacity 0.6–0.7

## 后端数据端点

| 端点 | 用途 |
|---|---|
| `GET /api/tasks/today` | 今天视图数据 |
| `GET /api/tasks/day?date=YYYY-MM-DD` | 非今天视图数据 |
| `POST /api/task/record` | 手建任务（可带 `scheduled_at`） |
| `POST /api/recurring` | 建循环任务（可带 `scheduled_hhmm`） |
| `POST /api/task/{id}/start \| pause \| resume \| complete \| abandon \| restore` | 状态流转 |
| `DELETE /api/task/{id}` | 删除 |

**spawn_daily_tasks 已修：** 若循环模板的 `scheduled_hhmm` 当天时刻已过（下午建"每天 9:00"），今天不 spawn，等明天。

## 数据模型（未变）

现有 schema 已支持全部场景，不用新 migration：

- `task` 表：`scheduled_at NULLABLE`、`status ∈ {idle, scheduled, executing, paused, completed, abandoned}`、`combo`（`recurring` 表示从模板 spawn）
- `recurring_task` 表：`scheduled_hhmm NULLABLE`（`'HH:MM'` 或 null）
