### 6. `core/memory.py` `_get_impressions` 的旧格式兼容分支

- 位置：`core/memory.py` 的 `_get_impressions()`
- 代码片段：
  ```python
  try:
      data = json.loads(raw)
      if isinstance(data, dict) and "impressions" in data:
          return data["impressions"]
      return []
  except json.JSONDecodeError:

  ```
- 问题：`except json.JSONDecodeError → []` 和 `不满足 dict 且含 impressions 键 → []` 两个 fallback 分支是为了兼容 Streamlit MVP 时代 ai_memo 存纯文本的旧数据
- 评估：v2 用全新 Supabase 项目 `ieakiihfsaqqyyjdyjtt`，不可能存在 pre-v2 数据；`_save_impressions` 是唯一写入点，总是写合法 JSON。两个分支**从 v2 视角看全是死的**
- 清理动作：
  - 简化成 `return json.loads(raw).get("impressions", []) if raw else []`（更激进）
  - 或保留 try/except 作为防御性（不信任外部数据写入），只删注释里的"兼容旧格式"说法
- 发现时间：2026-04-16（首次 simplify 时标为"保守留着无碍"，补录）
