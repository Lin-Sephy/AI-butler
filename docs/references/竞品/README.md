# 竞品观察

> 2026-04-15 Sephy 在小红书刷到的两款同赛道 app。归档留证。

---

## 📍 滚雪球

**赛道重合度：高。** 雪地 + 小雪球角色 + 成果累积反馈，跟我们方向撞了题材。

**宣发有 3000+ 赞**（不是空气产品）。

### 产品形态（见子文件夹截图 01-08）

1. 主页双输入框："我正在做什么 / 我想要做什么" → AI 生成计划
2. 开始前状态问卷：4 条滑块（时间 / 难度 / 大脑感受 / 情绪感受）
3. 极细粒度行动指令：单步卡片（"从床上坐起来" / "准备学习环境"）
4. 完成反馈：小雪球 + "执行力 +4" 数值
5. 子任务拆解：8 件微动作列表（放下手机 4s、喝水 4s、决定内容 8s...）
6. 完成后状态：再一轮评分问卷（难度 / 大脑 / 情绪 / 成就感）
7. 精力对照：开始前 40 → 完成后 44，带描述性总结

### 用户评论精确记录

**评论 1（原文）：** "想要一个类似'日程本'的功能，能在前一天把第二天要做的所有事情和路线都定制好，第二天醒来打开 app 就能直接上手了。目前用了一周左右，感觉还是很有效的，就是这种'点到点'的方式有点太碎片了，每次打开 app，再去设置起点终点，都需要付出很多琐碎的意志成本。"

**评论 2（原文只有前半句）：** "其实我一眼就看出来这个计划是 ai 生成的了，它做的还不如我。"

> Sephy 的判断（不是评论原文）：**"AI 味儿太冲，就是小管家训练前的状态"**——跟我们 v4.2 分层架构被推翻、回到 v4 基线简洁风的教训是同一件事。分层让 DS 更像"执行任务"，用户一闻就是 AI。

## 📍 精力快充

**赛道重合度：中。** 精力驱动任务管理，UI 风格不同。见子文件夹截图 01-03。

1. 精力时间轴：时间块任务流（10:00-12:00 看书 / 12:00-12:10 思维散步...）
2. 精力充电站：推荐计划 + 待开始/进行中/已完成三段 tab
3. 精力驱动任务：任务卡片带精力/难度/优先级/时长多维标签

---

## 借 / 不借（Sephy 已审）

| 项 | 决定 |
|---|---|
| 完成后白鼬做动作 + 今日专注时长累加 | ✅ 借 |
| 精力快充**时间栏下拉 UI**（数据页回顾视图参考） | ✅ 借 |
| 滚雪球**题材选得好**（成果可见化反馈） | ✅ 精神借鉴，不抄形式 |
| 滚雪球子任务极细粒度（4s/8s 微动作） | ❌ 太碎越做越烦 |
| 喝水计划 / 睡眠计划 | ❌ 不是重点不补 |
| AI 生成计划模式（用户出意图 → AI 吐计划） | ❌ **这正是我们要反的** |
| 两轮问卷（开始前 + 完成后） | ❌ 违反"打开即专注"原则 |

---

## 我们已经踩准的点（设计之前就定的，被竞品反向证实）

1. **冷启动不预填** — 滚雪球 4 条滑块问卷就是被评论 1 骂"付出很多琐碎的意志成本"的那种
2. **AI 做观察者不做生成者** — 任务内容来自用户聊天中的原话（"写论文引言段"），AI 只整理不编排，用户没机会拿"AI 的计划"跟"自己的计划"对比
3. **Prompt v4 基线的简洁风** — 分层架构 / 计划腔调正是评论 2 能一眼闻出"AI 味"的原因
