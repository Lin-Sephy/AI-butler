# 白鼬 Reference 素材

这里放白鼬动作 reference，小克做 SVG 桌宠时翻这个文件夹。

## 收集什么

### ✅ 要的

- **姿态照片**：站立偷看、拱背、蜷球、钻洞、跳跃、蹲坐、伸懒腰、舔毛、打哈欠、睡觉
- **跑动关键帧**（截图）：真实白鼬跑步周期 ~0.3-0.4 秒一循环，截 4-6 帧能看出节奏就够
- **表情特写**：好奇、警觉、困倦、放松
- **SVG 插画风白鼬/雪貂作品**（如果看到眼前一亮的），作画风投票

### ❌ 不要的

- 写实渲染风（我们走 SVG 扁平插画）
- 漫画化过头（小熊猫脸那种变形）
- 带复杂背景的（reference 看的是动物本身）

## 命名建议

用动作命名，方便小克翻查：
- `站立偷看_01.jpg`
- `蜷球睡_02.png`
- `跑动_帧1.png` / `跑动_帧2.png` ...
- `画风参考_SVG插画.png`

## 视频处理

Claude Code 看不了视频。如果你收集了视频：

1. **暂停在关键动作时截图**（PrtSc 或 Win+Shift+S），每段视频截 3-5 帧，这是最省事的做法
2. 实在要直接传视频，告诉小克路径，小克用 ffmpeg 抽帧（需要先装 ffmpeg）

## 当前素材清单（2026-04-14）

### 跑动周期（44 帧完整序列）
`跑动_01.png` → `跑动_44.png`
- 来自一段连续视频，保持序列顺序
- SVG 动画使用时**不需要全 44 帧**，选 4-6 个关键帧即可（真实白鼬跑步周期 0.3-0.4 秒）
- 建议挑选：起步、腾空、落地前、触地、后腿蹬出——这 4-5 帧能表达整个循环
