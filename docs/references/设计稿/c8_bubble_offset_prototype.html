C-8 thinking 泡泡偏移对比

当前 `StoatHalf.jsx:77` 用 `transform: translateX(40%)`，泡泡从"左缘贴容器中心"再往右偏泡泡自身宽度的 40%，最后视觉上在容器右侧 60% 附近——像 UI bug。
五档从"完全居中"到"当前偏右 40%"对比。红色细线是容器中心参考线。

参考线：
A
translateX(-50%)
完全居中
B
translateX(-25%)
略偏右
C
translateX(0%)
左缘贴中心
D ⭐ 推荐
translateX(15%)
微偏右对齐头部
E（当前）
translateX(40%)
偏出头顶
我的倾向：D（15%）。
理由：侧脸白鼬的头其实是朝右的，头顶中心比容器中心略靠右一点点（不像正脸头就在中央）。
  • A 完全居中（-50%） 对正脸合适，对侧脸看着像泡泡"往左歪"
  • B / C 折中，还是略偏左感
  • D 15% 视觉上泡泡对准侧脸头顶，不像 bug
  • E 40% 泡泡基本挂在白鼬耳朵后面了，像没对齐
不改的理由：如果你觉得当前 40% 其实是"故意偏出去假装白鼬在抬头看泡泡"，那保留也行。这条本来就不是必修，只是看起来像 bug 才放进必要清单。
