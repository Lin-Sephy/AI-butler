## 形象规格

### 风格路线：偏玩偶化（不是写实）

**比例：**
- 头身比 **1 : 2.5**（介于玩偶 1:2 与写实 1:3.5 之间）
- 眼睛占头部 **1/4 - 1/5**（比玩偶克制，比真实醒目）
- 身体**修长但曲线柔和**，不追求解剖学肌肉，也不做圆球

**识别锚点（不能丢）：**
- 黑圆眼 + 粉红鼻尖 + 内耳粉（**脸部三锚**）
- 胡须 **4-5 根细长**（细节感是"不幼稚"的关键）
- **蓬松黑尾尖**（不是点，是一撮）
- 粉色四足小垫

**守住的底线：**
- ❌ 不走玲娜贝儿式巨头
- ❌ 不走写实冷感纤瘦
- ❌ 不做二次元吉祥物
- ✅ 参考对标：Apple Journal / Headspace 吉祥物的比例与调性

## 优先级 & 打断逻辑

**优先级（高抢占低，one-shot 完成后回持续态）：**

```
8  思考中 (thinking)      — 可被用户打断
7  开心蹦跳 / 好奇探身 / 警觉 (one-shot)
5  歪头在听 (listening)
3  专注陪伴 / 偶尔抬头 (专注遮罩)
2  眨眼 / 基础待机
1  蜷睡 (sleeping，长时无操作默认)
```

**思考打断规则：**
- 用户在 API 未返回时发新消息 / 切页 / 刷新
- 思考泡泡 fade-out 0.15s，小白立即切回 idle
- API 正常返回时：泡泡淡出 + 按回复内容切下一个状态（listening / happy / curious）

**场景切换：**
- 聊天室 ↔ 专注遮罩 之间通过 `intro` 状态过渡
- 任务页 / 数据页 桌宠不出现

## 聊天页布局（2026-04-16 定，漫画气泡版）

> 此前 04-15 设计的"双 mode (Mode A 闲玩 / Mode B 聊天)"layout 已**被推翻**——实测时 mode 切换有割裂感，白鼬被压成 widget。改用**单一漫画式气泡布局**，白鼬永远主角。完整推翻过程见 commit `939c142` (双 mode savepoint) → `b76017e` (漫画版改造)。

### 当前布局（实现见 `frontend/src/pages/ChatPage.jsx`）

```
┌──────────────────────────────┐
│           📃  ⊕  ⚙️           │ ← 极简顶栏
├──────────────────────────────┤
│      ╭─────────────╮           │
│      │ 小白说...    │           │ ← 顶气泡：AI 最新一句，泡尾下指白鼬
│      ╰─────╲───────╯           │
│            ╲                   │
│        [白鼬全身居中 220px]      │ ← 永远主角，状态机活着
│            ╱                   │
│      [记下「xxx」][再聊聊]       │ ← 任务推荐按钮（如有），紧贴 AI 气泡下方
│                          ╭───╮ │
│                          │嗯 │ │ ← 你的气泡：右对齐到输入框右边，
│                          ╰───╯ │   堆叠 4 条，opacity 渐弱
├──────────────────────────────┤
│  [输入框________]    [发送]      │
└──────────────────────────────┘
```

### 关键约定

- **白鼬永远 full body 居中**，不分 mode
- **顶气泡（小白）** 只显最新一条，带泡尾向下指白鼬
- **底气泡（你）** 最多 4 条堆叠，最新在最下 opacity 1，老的渐弱（0.65 / 0.35 / 0.15），新消息推老的往上
- **任务推荐按钮** "[记下「xxx」N min] [再聊聊]" 紧贴 AI 气泡下方独立一行
- **气泡 >100 字**截断 + "更多"展开
- **thinking 时**：藏 AI 气泡 + 任务按钮，让白鼬头顶 3 点泡泡当唯一焦点；新回复来 sending 转 false → 显新气泡
- **历史视图**：右上 📃 按钮 → 切到传统消息列表（用 ChatBubble 组件）→ 左上 `<<` 返回主场
- **新建对话**：⊕ 按钮 confirm 后清空 messages（resetSession）

## SVG 实现参考（Clawd 路线）

**要抄的结构模式**（在 `C:/Users/Administrator/Desktop/clawd-on-desk/src/state.js`，纯结构参考，不碰视觉资产）：

- **`STATE_PRIORITY` 优先级表** —— 高优先级抢占低优先级
- **`ONESHOT_STATES` 自动回落** —— 一次性状态完成后自动回持续态
- **`MIN_DISPLAY_MS` 最小展示时间** —— 防止状态瞬闪
- **`pendingTimer` 抢占排队** —— 高优先级 one-shot 插队时的排队机制
- **SVG 状态切换 = SVG 替换 + opacity fade 过渡**（0→1，0.2s ease-out）—— 掩盖资产边界，切换不突兀
- **每个状态一个 SVG 文件**，内部用 CSS `@keyframes` 做动画
- **身体部件保留 JS hook**（`#eyes-js`, `#body-js`）用于动态 transform

**要砍的（Electron 桌面端特有，Web 用不到）：**
- mini mode / 边缘吸附
- `BrowserWindow` / `setIgnoreMouseEvents` / 置顶窗口
- `ipcMain` ↔ preload bridge
- 进程检测 / focus terminal / 光标跨屏追踪

**可选（v2 先不做，桌宠打磨阶段再加）：**
- 光标追踪 —— 实现"专注中桌宠抬头看用户"（眼睛角度跟光标联动）
