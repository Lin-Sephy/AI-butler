## v4.2.1 回退与新增（2026-04-05）

- 聊天 prompt 回退到 v4 基线简洁风格（一句话身份 + 6 条回复原则 + 5 条绝对禁止）
- v4.2 分层架构（本我层/情感层/行为层）实测被推翻：给 DS 的身份设定越多越像执行任务
- 核心结论修正：身份定义决定行为仍成立，但**不必要的强调会让 DS 不可控**
- 跨天检测：新的一天自动清空对话原文 + 情绪当天过期 + 摘要标记"昨天的"降权
- 身份定义对照实验：验证了禁令数量→焦虑→选择题的因果链、"接纳不完美"实际是降低自我审查而非焦虑等多项发现
- 详见 `docs/ds多版本prompt对比/prompt迭代研究：变量分析框架.md`

**第 3 步 + 第 4 步包含的改动（2026-03-30）：**
- 新增 task 表和 recurring_task 表
- 实现单任务闭环：创建→执行→暂停→继续→完成/放弃
- AI 推荐任务时长（suggested_minutes），用户可在执行面板切换
- AI 输出 task_type（work/rest），任务按类型分组展示
- 按钮展示条件从 combo A/D 改为「有 task_keyword」
- 侧边栏计划板：进行中 / 待完成 / 已完成（工作学习 + 休息分组）
- 循环任务：每日自动生成，侧边栏管理，点击直接开始
- 允许暂停后切换其他任务（多个 paused 共存）
- 休息任务完成后弹精力确认，工作任务不弹
- API 超时兜底区分冷启动和对话中途
- prompt 调优：combo C 有上下文时直接推荐、combo F 收窄触发条件、willingness 判断区分「不知道怎么做X」和「不知道干嘛」

**v2 架构重构包含的改动（2026-03-28）：**
- 砍掉 GLM，改用 DeepSeek 单次调用完成意图判断+回复生成
- 意图分类从四种意图改为意愿×状态二维矩阵（6种combo）
- 规则引擎从生成四路径改为守门校验
- 前端从四路径卡片改为对话式单推荐（combo A/D 展示开始+换一个按钮）
- API 调用带最近 10 轮聊天历史
- 精力值动态感知（AI 感知 vs 系统值偏差 ≥ 2 触发确认）
- 用户输入后立即显示消息 + spinner 加载提示

**v3 架构改造包含的改动（2026-04-01）：**
- 核心架构从"每轮强制 JSON"改为"聊天优先，按需干活"双模式
- AI 自主判断输出纯文本（聊天模式）还是 JSON（干活模式）
- 聊天模式下不触发守门校验、不展示按钮、不触发精力确认
- 改名"小白"，人设系统重做：5 种 MBTI 风格人设（INFP/INTJ/REST/INTP/Challenger），侧边栏可切换
- 人设描述从抽象标签改为成长背景描述，INTP 已加语言风格
- System Prompt 定位从"管家"改为"朋友"，combo 描述从硬规则改为柔性指引
- 记忆系统拆分为长期记忆（ai_memo）+ 每日记忆（daily_memo）
- 每日记忆是覆盖式快照（情绪/精力印象/当前任务/近期事件），按时间戳自动过期
- 新增绝对禁止：不推荐"打开窗户"等用户大概率不会做的动作、不出选择题

**v4 架构改造包含的改动（2026-04-02）：**
- 核心架构从"AI 自主判断输出模式"改为"聊天归 AI，推任务归 Python"
- prompt 拆分为聊天 prompt（自然聊天+信号输出）和任务 prompt（具体建议 JSON）
- intent.py 拆为 call_chat() + call_task()，大部分时候只调用一次
- 新增 should_trigger_task()：Python 根据信号 + 精力 + 任务栏决定是否触发推任务
- 触发规则保守策略：work/rest + wants_help 才触发，life 类不触发，frustrated 不触发
- 砍掉 combo、willingness、status、state_tags、resistance_source 等显式判断字段
- 任务栏信息传给 DS 聊天参考（进行中/已暂停/待完成/已完成）
- 信息参考优先级写入 prompt：用户当轮输入 > 对话历史 > 记忆 > 任务栏
- 聊天 prompt 去掉"2-3句话"长度限制
- 新增 find_matching_task()：用户提到的事项与任务栏匹配

**v4.1 改版包含的改动（2026-04-03）：**
- 按钮从"开始"/"换一个"改为"记录"/"再聊聊"
- "记录"点击后任务以 idle 状态写入任务栏，不自动开始执行
- "再聊聊"直接清除推荐回到聊天，删除 pending_switch 逻辑
- rest 类不再触发推任务，只有 work + wants_help 才触发
- 聊天 prompt 去掉精力档位，DS 靠对话自己感知
- 聊天 prompt 加自我意识（做自己、不编造、不重复）
- 人设风格指令精简，避免 DS "演戏"而非自然表达
- 记忆系统 v2：两级印象（draft/confirmed），触发 3 次 + 跨 2 天才升级
- 印象衰减：draft 7 天过期，confirmed 14 天降级（高频 30 天）
- 印象提取在同一次 API 调用中完成强化/推翻/新增判断，零额外成本
- 每日快照简化：只保留 emotion + current_task，砍掉 recent_events 和 energy_impression
- Session Memory：每 5 轮生成会话摘要，压缩长对话上下文
- 有摘要时 call_chat 从传最近 20 条改为"摘要 + 最近 5 条"，节省 token
