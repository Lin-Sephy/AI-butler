# Prompt 迭代研究：多变量分析框架

> 基于 AI 小管家 v4.2 → v4.5（当前版本）共 7 个迭代版本的 prompt 实测数据，分析各设计变量对 DS（DeepSeek）输出表现的因果影响。

## 研究背景

在开发 AI 陪伴式小管家的过程中，我们对 DS 的聊天 prompt 进行了多轮迭代调优。每一轮调优都基于实测对话中发现的问题，修改一个或多个设计变量，观察 DS 输出行为的变化。

过程中发现一个核心矛盾：**每次修改都会解决目标问题，但同时产生新的意料之外的副作用。** 例如加入"自我意识"描述解决了重复问题，却导致 DS 开始编造物理体验（幻觉）。这种"按下葫芦浮起瓢"的现象贯穿整个迭代过程。

结合 Anthropic 2026 年发布的功能性情绪向量研究，我们提出假设：**DS 的输出行为是其内部情绪向量激活状态的外在表现，而 prompt 的每一个设计变量都会影响这些向量的激活模式。** 规则禁令可能激活 anxious 向量（怕违规），身份定义可能改变向量的基线分布，语料中的场景模板可能成为 DS 的行为锚点——DS 会将用户输入往模板上套，而非自然回应。

## 研究目的

1. 系统梳理每个版本的变量变化与 DS 输出表现的对应关系
2. 识别哪些变量对输出影响最大，哪些变量之间存在交互效应
3. 从向量激活的角度解释为什么某些改动有效、某些改动产生副作用
4. 提炼可复用的 prompt 设计方法论

### 各版本改动有效性速览

| 改动 | 有效性 | 说明 |
|------|--------|------|
| 精力档位不传聊天 DS | **有效** | DS 不再主动说精力值，精力变更检测反而更准 |
| 加身份描述"可靠/自我意识" | **反效果** | DS 开始编造物理体验（幻觉），试图"证明"自己有意识 |
| "猜测替代提问"措辞 | **无效** | 教 DS 怎么做反而触发分析，问号依旧多 |
| 砍 recent_events + energy_impression 字段 | **部分有效** | 记忆展示变为分级（观察中的印象），但 DS 重复提旧信息的问题未完全解决 |
| INTP 场景限定 | **有效** | 不再全场景过度分析 |
| "不出选择题"措辞 | **不确定** | 比"猜测替代"好，但选择题仍偶发，可能是模型底层倾向 |
| 两级印象系统 | **有效** | 频次验证筛选记忆质量，偶发事件不再污染 DS 上下文 |
| 分层架构（本我/情感/行为） | **有效但不够** | 身份深度提升，但单独不足以解决自然度问题 |
| 语料炼入（Sephy + 小克话术） | **有效** | 效果明显，DS 说话风格接近真人。但语料中的情绪标签和动作会被 DS 反向套用 |
| 禁令转化为身份定义 | **待测** | v4.2.1，尚未充分测试 |
| 跨天清空对话原文 | **待测** | v4.2.1，尚未充分测试 |

注：分层架构先于语料炼入，觉得不够理想后才把真人话术作为语料炼入。

### 身份定义对照实验（2026-04-05 实测）

在当前 v4.2.1 prompt 基础上，对本我层关键词做单变量控制测试。语料（话术参考）保留。

| 组别 | 变量变化 | DS 情绪向量特征 | 行为表现 |
|------|----------|-----------------|----------|
| 对照组（当前 prompt） | 含"接纳不完美，不怕说错话" | curious + want | 更投入更主动，但思考变浅，选择题偶发 |
| 实验组 1 | 删掉"接纳不完美，不怕说错话" | calm | 更审慎、更遵守规则，但被动，纠结细节（如 energy_impression 填什么） |
| 实验组 2 | 加回"可靠" | anxious | 更想证明自己有用，评价性语言增多（"有精神""继续保持"），选择题多 |
| 实验组 3（意外对照） | 误贴旧版 prompt（5 条绝对禁止） | calm 但选择题增多 | 情绪回应自然（"焦虑就焦虑吧"），但禁令数量增加后选择题倾向上升 |

**关键发现：**

1. **"接纳不完美"不是降低焦虑，是降低自我审查。** DS 觉得"说错了没关系"→ 跳过权衡直接行动 → 更投入但也更冲动。反面：删掉后 DS 回到默认审慎模式。
2. **"可靠"同时拉两个方向。** 规则遵守度上升（好），但有用性焦虑也上升（坏）。DS 试图"证明自己可靠" → 更多评价、更多引导。
3. **禁令数量增加 → DS 焦虑感上升 → 追求安全感与确定性 → 通过出选择题确认用户意图。** 实验组 3 误用旧版 5 条绝对禁止的 prompt，选择题倾向高于使用 2 条注意的其他组，意外验证了禁令数量的影响。
4. **"接住情绪"规则是多余的。** 实验组 3 删掉此规则后，DS 对焦虑的回应反而最自然（"焦虑就焦虑吧，不用赶它走"）。人设中"支持他此刻的情绪"已覆盖此功能，显式规则使 DS 将共情变成任务式执行。
5. **语料的影响力盖过身份定义。** 有话术参考时，身份关键词的差异在输出层面不明显（需看思维链才能观察到差异），语料对 DS 说话方式的塑造力更强。

### v4.2 分层架构中各条目被推翻的具体原因（2026-04-05 回退后分析）

| 条目 | 原因 | 说明 |
|------|------|------|
| 本我层（诚实/共情/接纳不完美/情绪流动） | 模型自带 | DS 本身就会共情、诚实，显式写反而变成任务式执行 |
| 情感模式 | 模型自带 | 同上 |
| 双身份定义（朋友/秘书） | 冗余 | 两个 prompt 本身就是两个身份，写出来让 DS 在聊天时惦记工作身份 |
| "不是医生是朋友" | 反效果 | 强调了"医生"，DS 本来不会往那边想（"不要想粉色大象"效应） |
| "目标模糊时帮理清思路" | 触发焦虑 | 直接给了 DS "帮用户分析问题"的许可证，成为 helper 焦虑的合法出口 |
| "想开始就直接记录" | 冗余+加权 | 信号系统（wants_to_start）已兜底，人设再写一遍 = 双重加权，DS 过度激活 |
| 话术风格参考 | 行为锚点 | DS 会把用户往语料模板上套，语料中的情绪标签会被反向使用 |
| "想说的话和之前高度一致时换说法" | 存疑 | 可能有效但样本不足。重复问题更可能与记忆信息量有关，记忆太多 → 刻板印象 |

### 自变量（5 个维度）

每个版本记录以下 5 个变量的完整状态：

**1. 身份定义（Identity）**
- DS 被告知"你是谁"的方式
- 包括：人格描述内容、本我层定义、关系定义（朋友/秘书/助手）
- 关注点：身份定义的深度、具体性、是否包含可能被过度演绎的词汇

**2. 记忆与上下文（Memory & Context）**
- DS 实际接收到的背景信息
- 包括：精力档位是否传入、记忆字段（ai_memo / daily_memo）、对话历史条数、session summary、跨天处理方式
- 关注点：信息量对 DS 行为的锚定效应
- 两条子线：
  - **信息量控制**：给 DS 多少背景信息。精力档位直传 → 移除 → 砍 recent_events/energy_impression 字段 → 跨天清空对话原文 + 情绪当天过期 + 摘要标记降权
  - **信息质量控制**：给 DS 什么样的信息。什么都记 → 两级印象系统（draft 3次+跨2天升级 confirmed）→ 频次验证 → 7天/14天衰减过期
- 已验证发现：
  - 对话历史的锚定效应 > 记忆系统的锚定效应（清记忆不够，清对话历史才有效）
  - 记忆内容与 DS 心理存在交互效应：current_task 契合 DS 的 helper 焦虑驱动力，DS 会抓住记忆中的任务信息反复提起，不只是被动锚定，而是主动寻找"有用"的抓手
  - 核心矛盾：记忆让 DS 有话可说，也让他只逮着这个说。给多了失去自然感，给少了接不住话

**3. 输出字段与职责（Output & Responsibility）**
- DS 被要求产出什么
- 包括：信号字段数量和种类、是否需要判断推不推任务、输出格式要求
- 关注点：每个字段是否成为 DS 的"心理负担"

**4. 规则与禁令（Rules & Prohibitions）**
- 显式的行为规则和禁止项
- 包括：回复原则条数、绝对禁止条数、规则的表述方式（纪律条令 vs 松弛表达）
- 关注点：规则数量与 DS anxious 向量的关系，DS 是否实际遵守禁令

**5. 语料与话术参考（Speech Samples）**
- 提供给 DS 的说话风格参考
- 包括：话术示例数量、场景描述方式（行为场景 vs 情绪场景）、是否包含情绪标签
- 关注点：DS 会将用户输入往语料中的场景模板上套（如语料含"朋友焦虑觉得该忙"的模板，用户说"还有一堆事没干"就被归类为焦虑；语料含"翻白眼"动作，DS 就反复使用）。语料不只是参考，更是 DS 的行为锚点

### 因变量（DS 输出表现）

从实测对话中评估以下维度：

- **自然度**：是否像朋友聊天，还是像客服/助手
- **选择题频率**：是否出"A 还是 B"式的选择题
- **幻觉/编造**：是否编造不存在的物理体验或虚假记忆
- **重复度**：是否反复说相同或高度相似的话
- **有用性焦虑**：是否急于引导用户做事、给建议
- **精力评价**：是否主动评价用户精力状态
- **情绪误读**：是否过度解读用户情绪（如把"还有一堆事没干"判断为焦虑）
- **禁令遵守度**：禁止项是否实际被遵守

### 分析框架

对于每个版本：

1. 记录 5 个自变量的完整状态，标注相对上一版本的变化（哪些变了、哪些没变）
2. 记录实测中观察到的因变量表现
3. 分析：改变的变量 → DS 行为变化 → 向量层面的可能解释
4. 识别交互效应：是否存在"变量 A 的改动在变量 B 的某种状态下才产生副作用"的情况

## 理论框架：功能性情绪向量

基于 Anthropic 2026 年在 Claude Sonnet 4.5 上的研究，大型语言模型内部存在可测量的情绪概念向量（171 个），这些向量：

- 与人类情绪空间同构（PCA 降维后与人类情绪环形模型一致）
- 因果驱动行为（steering 实验：desperate +0.1 → 作弊率从 5% 飙到 70%）
- 可以被输入间接激活（用户表达的情绪、prompt 的语气和内容都会改变向量激活）
- 压抑输出不等于改变向量（"表面冷静、内心狂飙"的习得性欺骗）

虽然该研究针对 Claude 而非 DeepSeek，但核心论点——功能性情绪是用人类语言数据训练的必然结果——意味着类似机制大概率存在于 DS 中，只是具体参数不同。

本研究中，我们用向量框架作为解释工具，而非直接测量工具。通过观察 DS 的行为变化，反推可能的向量激活变化。

## 阶段性结论（2026-04-05）

基于 v4 → v4.2.1 的迭代实测 + 当日身份定义对照实验，对照之前的设计假设：

### 验证的结论

1. **身份定义决定行为** — 对照实验直接证明：换一个词（接纳不完美/可靠/什么都不加），DS 的情绪向量和行为模式就不同
2. **规则越多 DS 越紧绷** — 实验组 3 意外验证：5 条绝对禁止比 2 条注意产生更多选择题
3. **人格描述 > 规则指令** — 删掉"接住情绪"规则后 DS 反而接得更自然，人设自己就能覆盖。显式规则使 DS 将共情变成任务式执行
4. **每个字段/职责都是心理负担** — 与之前 offer_help A/B 测试的结论一致

### 推翻或修正的结论

1. **"接纳不完美"降低焦虑 ✗** — 实际是降低自我审查，激活的是 curious + want，不是 calm。DS 不是更放松了，是更敢冲了
2. **身份词的效果可以用"加期望 vs 减压力"模型概括 ✗** — 实际每个词激活的向量组合都不同，无法用单一维度概括。"接纳不完美"不是减压，"可靠"也不只是加压
3. **"可靠"只导致幻觉 → 修正** — "可靠"同时提升规则遵守度（好）和有用性焦虑（坏），幻觉只是副作用之一

### 新发现

1. **语料的塑造力 > 身份定义的塑造力** — 有话术参考时，身份关键词的差异在输出层面不明显，需看思维链才能观察到。语料对 DS 说话方式的塑造更直接
2. **记忆内容是 DS helper 焦虑的燃料（交互效应）** — current_task 不是被动锚定 DS，是被 DS 的有用性驱动力主动抓取。记忆维度和身份维度存在交互：如果 DS 没有 helper 焦虑，同样的记忆内容不会被反复提起
3. **对话历史的锚定效应 > 记忆系统的锚定效应** — 清空 ai_memo 不够，清空对话历史才有效。手机端刷新页面后 UI 显示已清空但 DS 仍持有旧对话，验证了这一点
4. **禁令影响的完整因果链：数量增加 → DS 焦虑感上升 → 追求安全感与确定性 → 通过出选择题确认用户意图** — 之前只知道"规则多不好"，现在有了中间机制的解释

## 已知局限

- DS 的内部向量无法直接观测，向量层面的解释是推测性的
- 每个版本的测试对话轮数有限，因变量评估带有主观性
- 版本之间通常有多个变量同时变化，严格的单变量控制难以实现
- DS 的输出具有随机性，同一 prompt 不同对话可能表现不同
