# 本地开发指南

## 启动后端

```bash
cd C:\Users\Administrator\Desktop\AI-butler
uvicorn api:app --host 0.0.0.0 --port 8001 --reload
```

- `--host 0.0.0.0`：让局域网设备（手机）也能访问，只在电脑上调试可以不加
- `--reload`：改了 Python 文件自动重启
- 跑起来后看到 `Application startup complete` 就行

## 启动前端

另开一个终端：

```bash
cd C:\Users\Administrator\Desktop\AI-butler\frontend
npx vite --host
```

- `--host`：让局域网设备能访问，只在电脑上调试可以不加
- 跑起来后会显示两个地址：
  - `Local: http://localhost:5173` — 电脑用这个
  - `Network: http://192.168.1.110:5173` — 手机用这个（IP 可能变，看终端输出）

## 手机测试

**前提**：手机和电脑连同一个 WiFi。

1. 改 `frontend/.env.local` 里的 API 地址为局域网 IP：

```
VITE_API_BASE_URL=http://192.168.1.110:8001
```

2. 改完后**必须重启前端**（Vite 不会热更新 .env 文件）
3. 手机浏览器打开终端里显示的 Network 地址（如 `http://192.168.1.110:5173`）
4. **测完改回来**：

```
VITE_API_BASE_URL=http://localhost:8001
```

**打不开常见原因**：
- Windows 防火墙拦了 5173 / 8001 端口
- 手机和电脑不在同一个 WiFi
- 后端没加 `--host 0.0.0.0`

## 关闭

在对应终端按 `Ctrl+C` 停掉。

如果端口被占（报 `address already in use`），杀掉所有 Python 进程重来：

```bash
taskkill /F /IM python.exe
```

## 查电脑局域网 IP

```bash
ipconfig | findstr "IPv4"
```
